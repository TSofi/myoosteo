# Roadmap

Planned work for MyoOsteo. Hours are rough estimates.

## 1. Learning experience (~15 h)
- [ ] Progress during a session (how many structures are done out of all).
- [ ] Forgiving answers: accept a small typo and show the correct spelling.
- [ ] Smoother transitions between structures.
- [ ] A new, more futuristic visual style.
- [ ] Better on phones: the keyboard should not cover the drawing.

## 2. More anatomy (~18 h)
- [ ] New regions: foot first, then the rest of the skeleton.
- [ ] Muscles for every region, not only the hand.
- [ ] Find openly licensed drawings where every bone or muscle is a separate shape, and record them in `ASSETS.md`.
- [ ] Check every name and its Latin name against an anatomy source.

## 3. Code quality (~9 h)
- [ ] ESLint and Prettier.
- [ ] Tests for every new region (the existing data checks already cover the format).
